# NIFTY50_STOCK_ANALYSIS
-> DESCRIPTION: "Data cleaning and analysis of Nifty 50 Stocks of 1 year and presented in Streamlit Dashboard and Power BI."

-> FEATURES: 1. Daily data for 1 year of yaml file is loaded and segregated to 50 CSV files for each stocks. 
             2. Data cleaned and analysed different features using pandas. 
             3. Analysed features are presented in Streamlit Dashboard and Power BI.

-> Tools Used: 1. Python, Pandas 2. PosgreSQL (for database) 3. Streamlit & Power BI(for Dashboard)

-> Install tools mentioned in requirements.txt file.. using command pip install

-> Database connection to local server using psycopg2 to connect with POSTGRESQL database.

-> To Run the application Use the command streamlit run st_dashboard.py

-> Dashboard is created also using Power BI.
